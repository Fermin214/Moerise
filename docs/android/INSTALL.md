# Android 安装与升级

Moerise Android 0.1.0 支持 Android 8.0（API 26）及以上系统，发行 APK 包含
`arm64-v8a` 和 `x86_64`。服务地址使用 Moerise 对外 Web 的 HTTPS 入口，只填写协议、
主机和可选端口。

## 安装

从发行附件下载 `moerise-android-v0.1.0.apk` 及同名 `.sha256` 文件。
核对 SHA-256 后，通过文件管理器安装；系统提示时为文件管理器开启安装应用权限。
ADB 安装命令：

```bash
adb install moerise-android-v0.1.0.apk
```

首次启动填写服务地址和 Moerise 用户名、密码。登录后可直接在主页写作。
断网时可继续编辑本机草稿，恢复连接后点击保存。显示“提交内容已存服务器”表示服务器
已确认；“草稿已存本机”表示内容只保存在这台设备。

`-unsigned.apk` 用于构建检查，需要发行签名后才能安装。
`.fixture` 与 `.benchmark` 包分别用于隔离服务流程和性能测量。

开发包名为 `io.github.fermin214.moerise.dev`，桌面名称为 Moerise Dev。开发包与
发行包各自保存登录状态和本机草稿；切换到发行包前，将需要保留的草稿提交到 Core。

## 升级

使用相同包名、相同签名且更高 `versionCode` 的发行 APK 覆盖安装：

```bash
adb install -r moerise-android-v0.1.0.apk
```

覆盖安装保留应用数据；不要先卸载。首次发行的 `versionCode` 为 1，后续发行必须递增。
签名身份发生变化时，Android 会拒绝覆盖安装。调试签名安装也应通过独立包进行测试，
避免与正式发行身份混用。

升级后检查主页草稿、设置中的本机草稿、保存结果不明的请求、登录状态和语言选择。
重试保存会沿用持久记录的请求；遇到来源冲突时先合并，或另存为新草稿。

本机数据库、凭据和附件排除云备份及设备迁移。卸载应用或在系统设置中清除数据会删除
本机草稿。应用设置中的“删除本机账号数据”只删除选中账号的本机内容，并退出登录。
服务器中的笔记通过 Core 和 Memos 保存。

## 发行附件

发行归档包括 APK、SHA-256、构建信息 JSON、本安装说明、第三方许可与声明。
R8 `mapping.txt` 用于定位发行崩溃，应随构建私有保存。
