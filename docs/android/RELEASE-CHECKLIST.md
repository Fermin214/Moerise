# Android 发版前真机检查

使用测试账号和候选 HTTPS 测试服。先做覆盖升级，再验证首次安装。

- [ ] **记录基线。** 记录成功的 `Main CI` 运行 ID、attempt、目标提交 SHA、设备型号和 Android API 版本。从该次运行的 `android-release` 下载正式签名 APK。
- [ ] **准备升级数据。** 在设备上安装上一正式版 `v0.3.0`，登录测试服。保存一条有唯一标记的笔记，用 Web 读回。断网，点击保存另一条带唯一标记的离线笔记，再输入一条中文草稿并保留在编辑器中。
- [ ] **覆盖升级并恢复同步。** 保持断网，直接覆盖安装候选 APK，重开应用，确认会话无需重新登录、中文草稿完整。恢复网络后等待同步，用 Web 确认待发笔记恰有一条，草稿没有上传。
- [ ] **体验快检（约 10 分钟）。** 新建笔记、行内编辑、归档后撤销、删除。试用关键词与混合搜索、回顾翻牌、漫步、观星（测试服启用时）和设置修改。
- [ ] **键盘与焦点。** 编辑时点击时间线空白、纵向滚动、打开后关闭卡片菜单、提交新建、提交或取消行内编辑。每次都应退出输入焦点并收起键盘。保持草稿并切到后台再返回，草稿应原样保留，键盘保持收起。
- [ ] **抽屉与卡片。** 开启系统动画。左手从距屏幕左缘约 32 dp 以外向右拖动，确认抽屉跟手，反向拖回半程以内再松手时收回。确认系统边缘返回、正文点击和纵向滚动、编辑区选字拖动及观星画布手势照常工作。检查卡片日期到正文间距，以及右上角菜单和上传异常标记的触控范围。
- [ ] **侧栏、诊断与退出。** 确认归档入口在浏览导航中，设置通用区显示上次同步时间并可立即同步。在本机改标签或归档后打开侧栏，核对日历与标签计数。在无近期错误时，打开诊断摘要并核对版本与连接状态。离线留下待发笔记，普通退出后重新登录应能恢复待发笔记。准备待发笔记、冲突副本与暂存附件，勾选清除后应显示数量并要求再确认，取消应保留数据，确认只清除该账号的本机数据。
- [ ] **验证首次安装与会话恢复。** 在一台干净设备上安装候选 APK，或在升级验证结束后清除候选应用的数据。首次打开欢迎页，确认遥测开关默认关闭。通过 HTTPS 登录测试服，读回一条已知笔记。进入 Android 系统设置，对候选应用执行「强行停止」。在 Web 端新建一条带唯一标记的笔记，再从桌面启动应用并下拉刷新，确认无需重新登录即可同步看到新笔记。
- [ ] **可选性能测量。** 在真机上感受冷启动、侧栏、翻牌和观星是否流畅。需要 P50/P95 时，在 USB 连接真机的 Linux 或 WSL2 中按[性能测量指南](../ANDROID.md#性能测量与-baseline-profile)运行 `scripts/android/benchmark.sh startup` 或 `scripts/android/benchmark.sh stars`。`Checks` 持续验证 `benchmark` 与 `profile` APK 可构建。
