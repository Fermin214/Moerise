# Android 发版前真机检查

使用测试账号和候选 HTTPS 测试服。先做覆盖升级，再验证首次安装。

- [ ] **记录基线。** 记录成功的 `Main CI` 运行 ID、attempt、目标提交 SHA、设备型号和 Android API 版本。从该次运行的 `android-release` 下载正式签名 APK。
- [ ] **准备升级数据。** 在设备上安装上一正式版 `v0.3.0`，登录测试服。保存一条有唯一标记的笔记，用 Web 读回。断网，点击保存另一条带唯一标记的离线笔记，再输入一条中文草稿并保留在编辑器中。
- [ ] **覆盖升级并恢复同步。** 保持断网，直接覆盖安装候选 APK，重开应用，确认会话无需重新登录、中文草稿完整。恢复网络后等待同步，用 Web 确认待发笔记恰有一条，草稿没有上传。
- [ ] **体验快检（约 10 分钟）。** 点主页底部胶囊新建笔记，从卡片菜单打开写作浮层编辑，检查归档后撤销和删除。试用关键词与混合搜索、回顾翻牌、漫步、观星（测试服启用时）和设置修改。
- [ ] **动效与触感。** 回顾卡片内短拖松手回弹、长拖切卡；页眉空白区右滑仍可打开抽屉。漫步起始预览轻落后静止，继续时观察上一条收进固定足迹位；检查观星拖动松手惯性与聚焦、复位。将系统动画时长倍率设为零，重复检查无位移或缩放；关闭系统触感后复制、保存、切换设置和翻牌，确认无触觉反馈。
- [ ] **键盘与焦点。** 在浮层内分别用取消、遮罩和系统返回关闭，确认草稿落盘，关闭后才可操作底页。短笔记打开时自动聚焦到末尾纯标签行之前，长笔记打开停在顶部。保持浮层打开并重建应用时应恢复目标草稿，主动关闭后重开应用应停在底页。
- [ ] **长文与速记。** 编辑约 64 KiB 的长文，检查中文组合输入、光标跟随及内部滚动。滚动主页后点底部胶囊，在归档、回顾或漫步点顶栏「+」。关闭或保存后核对首个可见卡片和偏移，或正在阅读的笔记和页内位置。选择附件后应回到原草稿，纯附件笔记可直接保存。
- [ ] **渲染与保存交接。** 检查段落及同一引用块内的单回车、句中标签原位可点、纯标签行不显示及标签不重复。改写带图片的卡片，在普通和筛选列表中提交，检查正文不回闪、已有图片不露白，待发标签不可点、确认后可按页筛选。分别复制待发和已同步卡片，粘贴核对 Markdown、纯标签行和首尾空白。
- [ ] **抽屉与卡片。** 开启系统动画。从距屏幕左缘约 32 dp 以外向右快甩，或拖开至少 32% 后松手，确认抽屉展开。向左快甩，或拖到展开比例不超过 68% 后松手，确认收回。浏览长卡片并收起，卡顶应返回可见范围。检查图片缩略图尺寸、双击与双指缩放、缩放后拖拽，以及超限或坏图的外部打开入口。
- [ ] **侧栏、诊断与退出。** 确认侧栏显示「归档」，底部用户名与齿轮共用一行且整行打开设置。断网冷启动或设置加载失败时，仍可从「设置 → 通用 → 账号」退出登录。普通退出后重新登录能恢复待发笔记。勾选清除待发笔记、冲突副本与暂存附件时显示数量并要求再确认，取消后保留数据。
- [ ] **验证首次安装与会话恢复。** 在一台干净设备上安装候选 APK，或在升级验证结束后清除候选应用的数据。首次打开欢迎页，确认遥测开关默认关闭。通过 HTTPS 登录测试服，检查 `/api/app/v1/capabilities` 的 `telemetry.allowed` 与隐私设置中的开关可用性一致，界面说明为 24 小时聚合统计。读回一条已知笔记，再从 Android 系统设置强行停止应用。在 Web 新建一条带唯一标记的笔记，重开应用并下拉刷新，确认会话恢复且能看到新笔记。
- [ ] **可选性能测量。** 在真机上感受冷启动、侧栏、翻牌和观星是否流畅。需要 P50/P95 时，在 USB 连接真机的 Linux 或 WSL2 中按[性能测量指南](../ANDROID.md#性能测量与-baseline-profile)运行 `scripts/android/benchmark.sh startup` 或 `scripts/android/benchmark.sh stars`。`Checks` 持续验证 `benchmark` 与 `profile` APK 可构建。
