# 私人 QQ 机器人

在 Web 或 Android 的「设置 → 回顾与推送」中展开 QQ 私聊配置，填写自己的 AppID 和 AppSecret 并保存。Core 通过 HTTPS 获取访问令牌与网关地址，通过 WebSocket（WSS）接收私聊事件，连接状态实时显示在设置页。

部署需要配置 `MOERISE_STATE_ENCRYPTION_KEY`（可用 `openssl rand -base64 32` 生成）。首次初始化字段为 `channel.qq_app_id` / `channel.qq_app_secret`，对应环境变量 `MOERISE_QQ_APP_ID` / `MOERISE_QQ_APP_SECRET`。

首条私聊会自动登记发送者的 OpenID 并处理该消息，请仅使用不对他人开放的私人机器人；登记后仅接收该私聊的消息。

| 发送内容 | 私聊回复 |
| --- | --- |
| 文字（保留空格、换行与 `#标签`） | 写入 Memos 私密笔记后回复“已保存” |
| `/回顾` 或 `/review` | 当天可读条数及最多三条短摘录 |
| `//回顾` 或 `//review` | 去掉第一个斜杠后按普通笔记保存 |
| 空白、超过 64 KiB、附件或不支持的消息类型 | 返回对应格式提示 |

在「设置 → 回顾与推送」中选择 QQ 作为推送目标并开启定时推送后，会在登记私聊地址后的下一个有内容时段发送摘要。主动推送受 QQ 平台额度和用户接收设置约束，平台拒收时可在发送记录查看原因并按需重试，不影响下一时段。

网络中断重连后，Core 从已保存的网关序号续传；会话失效时设置页会提示离线期间可能漏收消息。同一 AppID 可直接更换 AppSecret，更换 AppID 后由新机器人的首条私聊重新登记。从备份恢复时沿用绑定地址与时段，跳过历史未发任务。
