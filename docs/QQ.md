# 私人 QQ 机器人

在 Web 或 Android 的「设置 → 消息渠道 → QQ 私聊」填写自己的 AppID 和 AppSecret 并保存。Core 通过 HTTPS 获取令牌和网关地址，通过 WSS 接收事件。连接状态显示在设置页。部署需要独立的 `MOERISE_STATE_ENCRYPTION_KEY`，可用 `openssl rand -base64 32` 生成。部署文件的首次初始化字段是 `channel.qq_app_id` 和 `channel.qq_app_secret`，环境变量是 `MOERISE_QQ_APP_ID` 和 `MOERISE_QQ_APP_SECRET`。

第一次私聊会登记发送者的 OpenID，并处理这条消息。请使用只对笔记作者开放的私人机器人。之后只接收这个私聊的消息。

| 发送内容 | 私聊回复 |
| --- | --- |
| 文字，含空格、换行和 `#标签` | Memos 确认写入私密笔记后回复“已保存” |
| `/回顾` 或 `/review` | 当天可读笔记数及最多三条短摘录 |
| `//回顾` 或 `//review` | 将去掉第一个斜杠的原文保存为笔记 |
| 空白、超过 64 KiB 的文字、附件或特殊消息 | 相应的格式提示 |

在「回顾」设置中选择 QQ 并开启定时推送。有本人私聊地址后，从下一个有内容的时段开始发摘要。主动推送受 QQ 平台的额度和用户接收设置限制。平台明确拒收时可在发送记录查看原因，下一时段独立发送。

网络中断后，Core 从已保存的网关序号续传。QQ 会话失效时，设置页会提示离线期间可能有消息未收到。相同 AppID 可以更换密钥。更换 AppID 后由新机器人的第一条私聊登记地址。从备份恢复时沿用绑定地址和时段，跳过旧回复及旧推送。
