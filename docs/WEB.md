# Moerise Web 客户端指南

Moerise Web 是独立构建的高性能现代化浏览器客户端。它采用纯粹的原生技术栈（Vanilla JavaScript、HTML5 与 CSS3）构建，无冗余庞大的运行时框架依赖，开箱即用，轻快优雅。

---

## 一、界面与交互设计规范

1. **两栏式极简布局**：
   - **左侧导航栏 (260px)**：收纳主时间线、每日回顾、随机漫步、AI 洞察、认知地图，以及搜索、标签树、日历过滤和系统设置。
   - **主工作内容区 (最大 760px)**：居中排版，保持极佳的文字可读性，移动设备自适应收缩。
2. **沉浸式 Markdown 记录**：
   - 顶部提供即时输入卡片，支持 Markdown 语法高亮、原生 `#标签` 输入、图片与附件拖拽上传。
   - 快捷键支持：`Ctrl+Enter`（或 `Cmd+Enter`）快速保存，`Esc` 取消。
3. **时间线卡片就地编辑**：
   - 点击任意历史卡片可直接就地编辑，无需弹出多层模态弹窗；修改后保存保持原有创建时间排序不变。

---

## 二、双语国际化机制 (i18n)

Web 界面原生支持**简体中文与英语**：
1. **自动探测与手动切换**：
   - 首次访问自动读取 `navigator.language`，未命中中文时默认显示英文；
   - 登录页面与侧边栏底部提供一键语言切换。
2. **零闪烁局部热更新**：
   - 语言偏好保存在本地存储 `moerise.language`；
   - 切换语言只增量替换 DOM 中的绑定文案与 ARIA 辅助标签，绝不刷新页面，当前正在编辑的草稿、圈选材料、地图视口与进行中的 AI 对话流不受任何影响。
3. **内容保真原则**：
   - 国际化仅翻译界面控件与系统提示；用户的笔记原文、标签名、附件文件名、自定义 Prompt 与历史聊天记录绝对保留原样，不做任何机器翻译。

## 二、2D 认知地图画布交互

认知地图提供直观的可视化思维全景图，使用 HTML5 Canvas 高性能渲染：
- **手势与鼠标控制**：支持鼠标左键拖拽平移、滚轮缩放，移动端支持双指缩放。
- **键盘导航支持**：
  - `方向键 (↑ ↓ ← →)`：平移视口
  - `+ / -`：缩放画布
  - `Home`：一键复位并居中显示全景图
  - `R`：重新读取当前已发布的最新快照
  - `Tab / Shift+Tab`：在临近点位间轮转选中，按 `Enter` 打开阅读卡片
- **实时穿透查阅**：点击任意节点弹窗呈现笔记摘要，点击详情可直接拉取 Memos 最新实时原文与附件，并支持一键返回原地图视口。

## 三、构建与本地运行

Moerise Web 仅需 Node.js 24 或更高版本，构建产物零第三方运行时依赖。

```bash
# 进入工程根目录安装依赖并构建
npm --prefix web ci
npm --prefix web run build

# 启动 Web 前端服务
npm --prefix web start
```

### 构建流水线特性
- `build.mjs` 负责静态资产编译与 CSS 合并，输出至 `web/dist/`；
- 资源文件名注入构建内容哈希摘要，生产环境静态文件支持 `max-age=31536000, immutable` 强缓存；
- 构建期自动生成 Brotli (`.br`) 和 Gzip (`.gz`) 双预压缩文件，服务端自适应输出。

## 四、环境变量与同源网络拓扑

Web 服务端通过固定反向代理将 `/api/app/v1/*` 请求安全转发给 Core 核心服务：

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `CORE_ORIGIN` | `http://127.0.0.1:8787` | Moerise Core 内部监听地址（仅在服务端内部使用） |
| `PUBLIC_ORIGIN` | `http://localhost:3000` | 浏览器访问的公开对外域名与协议（生产环境必须为 HTTPS） |
| `HOST` | `0.0.0.0` | Web 服务监听地址 |
| `PORT` | `3000` | Web 服务监听端口 |

## 五、健康检查与存活探测

Web 服务提供遵循业界标准的存活与就绪探测接口：

| 路径 | 方法 | 成功状态 | 检查逻辑与依据 |
| --- | --- | --- | --- |
| `/health/live` | GET, HEAD | 200 `{"status":"ok"}` | 验证静态构建产物 `dist/index.html` 处于可读状态。 |
| `/health/ready` | GET, HEAD | 200 `{"status":"ready"}` | 验证静态产物正常，且内部连接 Core 的 `/health/ready` 正常响应。 |
