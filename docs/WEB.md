# Moerise Web 客户端指南

Moerise Web 使用原生 JavaScript、HTML 和 CSS，独立构建、部署，通过同源代理访问 Core。浏览器端没有第三方运行时依赖。

---

## 一、界面与交互设计规范

1. **桌面与手机布局**：
   - **桌面侧栏**：宽度随窗口调整；Moerise 标题下依次排列日历、页面导航、搜索和标签，底部提供设置和账号操作。
   - **手机工具栏**：左侧菜单按钮打开导航侧栏，日历、标签、设置和账号操作集中在侧栏内。也可从屏幕左边缘右滑打开、在侧栏内左滑关闭；选择页面或筛选条件后自动收起。
   - **手机搜索**：点击放大镜展开搜索栏，支持关键词、语义和混合搜索。收起搜索栏保留查询词与搜索方式。
   - **工作区与阅读列**：正文限制阅读宽度，地图铺满工作区；窄窗口使用导航抽屉。
   - **标签与日历**：已选标签置顶，其余按笔记数量排序；日历、导航、搜索与标签共用一个纵向滚动区。设置和账号随侧栏向下滚动收起，向上滚动立即回到侧栏底部；滚动到顶部、打开抽屉或切换布局时显示。键盘聚焦底部操作时直接显示，减少动态效果模式关闭显隐动画。切回页面时后台刷新，加载或失败时保留已有内容。
   - **页面恢复**：时间线、每日回顾和地图优先恢复会话内已有内容，后台检查更新；笔记或设置变更时使相关缓存失效，退出账号时清空。
   - 保存笔记后只更新对应卡片。后台刷新按首条可见笔记及其屏内位置恢复阅读进度。标签和日历在一分钟内复用，写入后按受影响的月份、标签和笔记状态更新。首屏加载后再预取最近会话和已启用的星图快照。
   - **键盘进入正文**：提供“跳到正文”入口；跨页导航聚焦主内容，时间线筛选保留搜索焦点，从详情返回时恢复来源笔记链接的焦点。
   - **搜索输入法**：中文组词期间不检索，组合输入结束后防抖查询；确认候选的回车不会提前提交。
2. **沉浸式 Markdown 记录**：
   - 顶部输入卡片在正文为空时显示浅色提示“今天想到了什么……”，支持 Markdown 正文输入、原生 `#标签`、图片与附件上传；保存后按 Markdown 展示。
   - 笔记的原生标签集中显示为去重胶囊，正文省去对应的标签标记。`# 标题`、`## 标题` 按 Markdown 标题层级显示；代码、链接与转义标记保留字面内容。编辑和保存使用原始 Markdown。
   - 快捷键支持：`Ctrl+Enter`（或 `Cmd+Enter`）快速保存，`Esc` 取消。
   - 新笔记和编辑草稿保留在会话内。存在输入或结果不明的写入时，刷新或离开站点会触发浏览器确认。退出账号前可选择继续编辑或放弃修改。登录失效后，同一实例的同一作者重新登录可恢复草稿。续期时发现实例或作者已更换，页面会清空草稿和缓存并返回登录页。正文、附件和密钥不写入浏览器持久存储。
3. **时间线卡片就地编辑**：
   - 在历史卡片的「更多操作」菜单选择编辑，即可就地修改；保存后保持原有创建时间排序不变。
4. **回顾与漫步**：
   - 每日回顾使用堆叠卡片；随机漫步可随机开始或点选漂浮笔记作为起点。
   - 漫步提前准备下一条，点击继续时复用结果或在途请求；切换页面、停止漫步或更换起点时取消预取。
   - 两页标题位置一致，加载、空结果和错误提示共用固定内容区；长正文在阅读框内滚动，卡片动画遵守浏览器的减少动态效果设置。
5. **设置**：
   - 按模块使用顶部横向页签，高级参数直接展示；切换页签保留输入，统一保存。
   - 修改后导航离开、浏览器返回或重新加载设置会请求确认；字段错误关联对应控件并定位到所属页签。语言偏好即时生效，不计入待保存的设置修改。
6. **AI 洞察**：
   - 在「添加笔记」里按日期或标签选材。「应用日期」勾选整段日期内的正常和归档笔记，多个标签取并集。「查看已选」可移除筛选范围外的笔记。关闭选材框会放弃修改。
   - 候选笔记和会话历史滚动到页尾后继续加载，也可用键盘按「加载更多」。批量选择期间可逐条调整，或停止统计并改为逐条勾选。超过 20,000 字时须减少选材，超过 1,000 条来源时需缩小范围或逐条选择。
   - 首问前可在输入框内点击「一键洞察」。Enter 发送，Shift+Enter 换行。上翻阅读时新回复保留阅读位置，点击「回到最新」恢复跟随。发生断线时先检查服务端回复，再决定是否重新生成。
   - 「更多」提供新建、历史、修改材料、保存和删除。材料修改只用于之后的提问。「保存为笔记」可将所选提问和回答按对话顺序保存为一篇笔记。已停止的部分回答可复制，保存前须确认。删除对话后，笔记仍保存在 Memos。
   - 保存结果不明时，同一标签页会暂存操作键、消息引用、语言和确认选项。刷新、切换对话或重新登录后，可回到同一实例、同一作者的原对话重试。保存成功或收到明确的写入失败结果后清除暂存。

操作菜单共用方向键、Home、End、Esc 和 Tab 行为。焦点使用深蓝描边，粗指针设备扩大菜单、回顾位置和星图工具的点击区域，高对比模式使用系统焦点色。

## 二、双语国际化机制 (i18n)

Web 界面原生支持**简体中文与英语**：
1. **自动探测与手动切换**：
   - 首次访问按 `navigator.languages` 的顺序匹配中文或英语，未匹配时显示英文；
   - 登录页面提供语言切换，登录后在「设置 → 通用」选择语言，也可恢复跟随浏览器。
2. **零闪烁局部热更新**：
   - 语言偏好保存在本地存储 `moerise.language`；
   - 切换语言增量替换 DOM 中的绑定文案与 ARIA 辅助标签，不刷新页面，不重建设置表单；跟随浏览器时清除手动语言偏好。
3. **内容保真原则**：
   - 国际化仅翻译界面控件与系统提示；用户的笔记原文、标签名、附件文件名、自定义 Prompt 与历史聊天记录绝对保留原样，不做任何机器翻译。
   - 正文子树不参与翻译遍历，避免长回复在流式更新时重复扫描。

## 三、观星交互

观星以均衡 UMAP 按语义组织真实笔记，采用深蓝黑背景、清晰星核和克制的密度辉光。点击主题聚焦，悬停预览笔记，点星读取原文。

「设置 → 通用 → 启用观星」独立控制入口，默认开启。关闭后导航隐藏观星，直接访问 `/map` 显示关闭状态；重新开启后恢复入口与已有快照，Embedding 功能不受影响。

远景呈现星群轮廓与少量主题名称，放大后展开子主题和笔记摘要。工具栏提供全屏和回到全图。点星或从“未定位笔记”列表选择笔记，会在图内读取原文。窄屏使用底部阅读卡，宽屏使用侧边阅读区。按 Esc、返回或点空白关闭卡片，镜头位置保持不变。布局更新期间可继续阅读已有快照。

- **鼠标与触摸**：拖动平移、滚轮或双指缩放。
- **键盘导航支持**：
  - `方向键 (↑ ↓ ← →)`：平移视口
  - `+ / -`：缩放画布
  - `Home`：一键复位并居中显示全景图
  - `R`：重新读取已发布的最新快照
  - `Tab / Shift+Tab`：在临近点位间轮转选中，按 `Enter` 打开阅读卡片
- **实时查阅**：点选笔记读取最新正文和附件，宽工作区显示右侧详情，窄工作区显示底部详情；打开独立笔记后可返回原地图视口。
- **后台绘制**：支持 Worker 和 OffscreenCanvas 时，星核、辉光和密度纹理在后台准备，页面合成完成的画面并维护可访问点位。失败时使用同一算法分批计算与绘制；切页时销毁任务。

## 四、构建与本地运行

Moerise Web 仅需 Node.js 24 或更高版本，构建产物零第三方运行时依赖。

```bash
# 进入工程根目录安装依赖并构建
npm --prefix web ci
npm --prefix web run build

# 启动 Web 前端服务
npm --prefix web start
```

### 构建流水线特性
- `build.mjs` 负责静态资产编译与 CSS 合并，输出至 `web/dist/`；源码中的 CSS 导入在构建期合并，浏览器无需逐层请求；
- 资源文件名注入构建内容哈希摘要，生产环境静态文件支持 `max-age=31536000, immutable` 强缓存；
- 构建期自动生成 Brotli (`.br`) 和 Gzip (`.gz`) 双预压缩文件，服务端自适应输出。

### 浏览器能力与回退

基础交互使用原生 ES Modules、`dialog.showModal()`、AbortController 和容器查询。Popover、Invoker Commands、CSS Anchor Positioning 与 focusgroup 通过能力检测增强菜单；缺失时提供等价的打开、定位和键盘处理。菜单始终显式声明 ARIA 角色，避免键盘能力与无障碍语义支持不同步。

屏外时间线卡片在测得尺寸后采用 `content-visibility:auto` 与尺寸占位，首屏和编辑中的卡片正常布局；不支持时按普通列表呈现。图片沿用延迟加载，异步解码；会话内记录真实宽高，重现时建立占位，正文已引用的图片不在附件区重复显示。退出时清空尺寸缓存。

设置诊断、地图与恢复中的聊天轮询在页面隐藏时暂停，恢复可见时重新读取。浏览器流程默认运行 Chromium，通过 `MOERISE_PLAYWRIGHT_ENGINE=firefox` 或 `webkit` 选择其他引擎。

## 五、环境变量与同源网络拓扑

Web 服务端通过固定反向代理将 `/api/app/v1/*` 请求安全转发给 Core 核心服务：

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `CORE_ORIGIN` | `http://127.0.0.1:8787` | Moerise Core 内部监听地址（仅在服务端内部使用） |
| `PUBLIC_ORIGIN` | `http://localhost:3000` | 浏览器访问的公开对外域名与协议（生产环境必须为 HTTPS） |
| `HOST` | `0.0.0.0` | Web 服务监听地址 |
| `PORT` | `3000` | Web 服务监听端口 |

## 六、健康检查与存活探测

Web 服务提供遵循业界标准的存活与就绪探测接口：

| 路径 | 方法 | 成功状态 | 检查逻辑与依据 |
| --- | --- | --- | --- |
| `/health/live` | GET, HEAD | 200 `{"status":"ok"}` | 验证静态构建产物 `dist/index.html` 处于可读状态。 |
| `/health/ready` | GET, HEAD | 200 `{"status":"ready"}` | 验证静态产物正常，且内部连接 Core 的 `/health/ready` 正常响应。 |
