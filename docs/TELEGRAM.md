# Telegram 私聊与回顾推送

在 Telegram 中联系 **@BotFather** 使用 `/newbot` 创建机器人，然后在 Moerise「设置 → 回顾与推送」的 Telegram 区域填入 Bot Token 并保存。点击「打开机器人」并在聊天窗口点击「开始」，Core 会通过启动参数识别并登记本人私聊。

从仅支持推送的旧版本升级时，原有 Chat ID 继续接收定时回顾；首次启用私聊速记或查询回顾，需登录设置页打开机器人并点一次「开始」。

文字速记保留空格、换行和 `#标签`，写入 Memos 后回复确认；图片与附件会返回格式提示。单独发送 `/回顾` 或 `/review` 查询当天摘录，发送 `//回顾` 或 `//review` 保存字面内容。

在「设置 → 回顾与推送」中选择 Telegram、开启推送并设置时段。目标 Chat ID 留空时默认发往已登记的本人私聊；若需发往其他私聊、群聊或频道，填写对应数字 ID 并授予机器人发送权限（群聊或频道会收到入选笔记的正文和图片）。修改推送目标不影响本人私聊的速记和回顾查询。

Core 通过长轮询收件；若机器人已在外部配置 Webhook，设置页会显示冲突提示，原有定时推送仍可继续。私聊收件需配置 `MOERISE_STATE_ENCRYPTION_KEY`。首次初始化支持 `MOERISE_TELEGRAM_BOT_TOKEN` 与 `MOERISE_TELEGRAM_CHAT_ID`。

定时推送先发 `Daily review`，随后按笔记顺序发送正文、原图文件、标签和创建日期。长正文按 4,096 个 UTF-16 单元切分，纯空白片段以文本文件发送。触发限流时遵守平台返回的冷却时间；某一片发送结果不明时跳过该批后续片段，可在发送记录核对后手动重试，详见[通知调度](NOTIFICATIONS.md)。
