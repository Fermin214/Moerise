# Moerise 检索与随机漫步

Moerise 内置统一的高性能检索服务（`SearchService`），为 Web 客户端、开放机器 REST API 以及只读 MCP 协议提供中文关键词检索、高维向量语义检索以及多通道融合的混合检索能力。

---

## 一、三种检索模式

| 模式 (`mode`) | 底层技术 | 是否依赖向量模型 | 行为与特性 |
| --- | --- | --- | --- |
| `keyword` | SQLite FTS5 中文预分词 | 否 | 精确匹配中文词汇、英文单词与标签，性能极高，开箱即用。 |
| `semantic` | 高维向量点积 / 余弦相似度 | 是 | 理解查询的深层语义，召回用词不同但含义相近的笔记。 |
| `hybrid` (默认) | FTS5 + 向量 + RRF 融合 | 可选 | 兼顾精确关键词匹配与语义联想；未配置向量模型时**自动优雅降级**为关键词排序。 |

---

## 二、多通道召回与混合排序算法

### 1. 中文预分词全文索引 (FTS5)
- **中文切词算法**：对连续中文正文生成单字与相邻双字（Bi-gram），英文与数字自动转小写并保留词干。
- **跨块边界保护**：在文本分块交界处的相邻中文双字会同时记入两侧分块，防止用户短查询在分块缝隙处漏召回。
- **安全防注入**：关键词转化为参数化 FTS5 匹配表达式，避免 SQL 注入或特殊字符报错。

### 2. 向量语义扫描
- 内存常驻当前活跃代次的 `float32` 向量矩阵，避免每次查询重复读取磁盘。
- 采用余弦相似度精确匹配，根据主机 CPU 核心数自适应启用多协程分片并行点积计算，计算耗时通常在毫秒级。

### 3. 多通道 RRF 排名融合 (Reciprocal Rank Fusion)
混合检索分别从关键词通道、标签匹配通道与语义通道各召回前 100 个候选片段，采用 RRF 算法计算综合分：

$$RRF\_Score(d) = \sum_{m \in \{keyword, tag, semantic\}} \frac{1}{60 + rank_m(d)}$$

- 同一篇笔记内取最高片段分作为整篇笔记分数；
- 返回排序结果，并附带命中高亮片段及所激发的信号类型（`keyword`、`semantic` 或 `tag`）。

## 三、来源复查保障 (Source Verification)

为了杜绝缓存脏数据并确保绝对的数据主权，检索流程在返回最终结果前执行严格的**来源复查**：
1. 校验当前实例的 Memos 绑定作者身份；
2. 召回候选笔记后，实时通过 Memos 官方 API 拉取最新原文；
3. 核验每篇候选笔记的存在性、可见性、作者归属与最新修改时间；
4. 若笔记已被删除、归档过滤或不再属于当前作者，系统自动剔除该候选并异步修正索引投影，确保用户查阅到的始终是真实有效的最新数据。

---

## 四、随机漫步 (Random Walk)

随机漫步旨在打破标签与分类的局限，让用户在笔记宇宙中自在穿梭，激发灵感碰撞：
1. **起点选择**：可从指定的一篇笔记出发，或随机挑选全库中的任意笔记作为漫步起点。
2. **候选抽取**：计算当前笔记与全库其他笔记的向量语义相似度，提取强相关与中弱相关的候选池。
3. **受控随机探索**：在候选池中按概率随机步进至下一篇笔记，不设固定的标签偏好。
4. **单次漫步去重**：在同一次漫步序列中，系统严格记录走过的路径，后续步进绝不会重复回到已经浏览过的笔记。
5. **优雅边界反馈**：当所有相关联候选均已被访问完时，明确提示漫步已抵达边界，用户可选择重新开启全新漫步。
