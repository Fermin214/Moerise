# 每日回顾

每日回顾从旧笔记中随机选取内容。用户阅读即可，无需完成任务或打卡。Core 固定每天的笔记集合，REST、只读 MCP 和飞书推送共用同一结果。飞书只推送完整文字正文和原文链接，不发送图片、附件或附件链接。

## 选择规则

`review` 控制候选范围与每次数量：

| 字段 | 默认值 | 约束与含义 |
| --- | --- | --- |
| `count` | 3 | 每批条数上限，允许 1 至 20 条 |
| `min_age_hours` | 72 | 笔记创建后的等待小时数，0 至 87600 |
| `recent_days` | 7 | 排除最近若干当地日内已选中的笔记，0 至 3650；0 表示关闭近期排除 |
| `include_archived` | false | 是否将归档笔记纳入候选 |

先按作者、等待期、近期历史和归档开关过滤，再等概率打乱候选顺序并抽取。没有历史优先、纪念日优先或主题配额。同一主题的多条笔记可以同时出现。候选不足时展示实际数量，候选为空时固定空结果，飞书不发送消息。

近期排除按配置时区的日期计算，例如 7 天包含选取当天及前 6 天。等待期按实际经过的小时计算。只有图片或文件附件的笔记也可入池，但没有文字正文时不产生飞书消息；原始附件继续保存在 Memos。

选中前从 Memos 获取原文，排除删除、作者不符、状态改变和过新的资源。来源故障返回错误并由后台重试，不当作空候选处理。首次全量同步完成后才生成回顾，避免将尚未建立的索引误判为空池。

## 批次与记录

后台在每个当地日生成结果，与推送开关分开。关闭通知后仍可读取当天回顾；API 首次显式创建也使用同一服务。结果尚未生成时，只读入口返回 `REVIEW_NOT_FOUND`。

批次按来源实例、账号、时区和当地日期读取。修改数量、等待期、排除期或归档开关不会替换当天结果，新规则从下一天使用。重启、增加推送时段和切换入口不会重新抽样，空结果同样固定。

原生 REST 另有显式换组、打开和略过接口，供已有调用方使用；外部 MCP 和飞书文字直记不提供这些操作。换组要求幂等键，同键重试返回同一结果。普通查看及推送不会写入打开或略过记录。

每个条目保存资源名、选中时的来源摘要与选中时间。打开、略过分别记录首次发生时间，重复操作保持原时间，两种记录可以同时存在。发送记录由通知模块独立保存，推送成功不等于打开。

读取已有批次时再次验证来源身份并逐条获取最新原文。已删除或不再属于绑定作者的资源保留历史位置，响应以 `unavailable: true` 表示，省略正文，不填入新笔记。来源不可用或身份检查失败时整个请求失败，不输出旧正文。

## 配置迁移与恢复

省略时长字段的配置使用 72 小时和 7 天。已有 JSON 中显式填写的时长原值保留；要采用新默认值，可删除这两个字段或显式修改。旧 `topic_limit` 字段仍可读入，但不参与选择，可以删除。旧批次和历史继续使用，规则调整不会重新生成当天结果。

重启后直接读取已有批次。索引重建不删除回顾表；重建期间已有批次仍按资源名复查来源。在线产品状态快照包含全部回顾记录，恢复后沿用批次标识和条目状态。推送次数、时段和发送恢复见[调度与发送队列](NOTIFICATIONS.md)，接口见 [API v1](API-V1.md#每日回顾与-mcp)。
