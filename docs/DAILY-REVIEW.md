# 每日回顾

每日回顾的产品规则见 [PRD 第三章](PRD.md#1-每日回顾-daily-review)。全天计划、不同推送时段的分配、普通文件排除及最近一次补发在 [ROADMAP 3.6](ROADMAP.md#阶段三完整-web-与一体化-compose)交付。

以下说明既有日批次协议、配置与恢复。Core 固定每天的笔记集合，REST、只读 MCP 和飞书读取已有结果；旧换组和阅读记录接口仅作为迁移前协议说明，不用于 Web 回顾体验。

飞书每次推送先单独发送一条 `「今日回顾」`，整次只发一次。随后逐篇发送完整正文、原图，最后发送 `#标签  创建于YYYY-MM-DD`；无标签时只发 `创建于YYYY-MM-DD`。日期取来源 `create_time`，按配置 `timezone` 换算。不附加链接、片号或状态提示，普通文件不推送。没有可发送正文或图片的笔记不发尾注，整次均无内容时也不发标题。

## 选择规则

`review` 控制候选范围与每次数量：

| 字段 | 默认值 | 约束与含义 |
| --- | --- | --- |
| `count` | 3 | 每批条数上限，允许 1 至 20 条 |
| `min_age_hours` | 72 | 笔记创建后的等待小时数，0 至 87600 |
| `recent_days` | 7 | 排除最近若干当地日内已选中的笔记，0 至 3650；0 表示关闭近期排除 |
| `include_archived` | false | 是否将归档笔记纳入候选 |

先按作者、等待期、近期历史和归档开关过滤，再等概率打乱候选顺序并抽取。同一主题的多条笔记可以同时出现。候选不足时展示实际数量，候选为空时固定空结果，飞书不发送消息。

近期排除按配置时区的日期计算，例如 7 天包含选取当天及前 6 天。选入即写排除历史，独立于阅读和送达。等待期按实际经过的小时计算。既有选择器允许只有图片或普通文件的笔记入池，纯文件无正文时不产生飞书消息；3.6 在抽取前排除这类纯普通文件笔记。原始附件继续保存在 Memos。

选中前向 Memos 复查原文，过滤已删除、作者不符、状态不符或未到等待期的笔记。来源故障返回错误，由后台重试；空候选才生成空批次。首次全量同步完成后才生成回顾。

## 批次与记录

后台按配置时区每天生成回顾，关闭通知后也会生成；API 首次创建使用同一规则。结果生成前，只读入口返回 `REVIEW_NOT_FOUND`。

批次按来源实例、账号、时区和当地日期读取。修改数量、等待期、排除期或归档开关不会替换当天结果，新规则从下一天使用。重启、增加推送时段和切换入口不会重新抽样，空结果同样固定。

旧 REST 提供显式换组、打开和略过接口；外部 MCP 和飞书不支持这些操作。旧换组要求幂等键，同键重试返回同一结果；只有显式操作写入打开或略过记录。3.1 关闭外部机器写入口，3.6 不再开放换组或将打开/略过作为 Web 必要操作，保留历史批次和记录恢复。

每个条目保存资源名、选中时的来源摘要与选中时间。打开、略过分别记录首次发生时间，重复操作保留原时间，两种记录可以同时存在。通知模块独立保存发送记录。

读取已有批次时再次验证来源身份，逐条获取最新原文。已删除或不再属于绑定作者的资源保留历史位置，以 `unavailable: true` 标记，省略正文，不填入新笔记。来源不可用或身份检查失败时，整个请求返回错误。

## 配置与恢复

省略时长字段时使用 72 小时和 7 天，显式填写时使用配置值。`topic_limit` 不参与选择，无需配置。调整规则不会重新生成当天结果。

重启后直接读取已有批次。索引重建不删除回顾表；重建期间已有批次仍按资源名复查来源。在线产品状态快照包含全部回顾记录，恢复后沿用批次标识和条目状态。推送次数、时段和发送恢复见[调度与发送队列](NOTIFICATIONS.md)，接口见 [API v1](API-V1.md#每日回顾与-mcp)。
